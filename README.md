# A collection of materials for teaching Differential Manifolds course in CAU

## Lecture notes

`Notes/LectureNotes/` contains a revised study reprint of Frank W. Warner's
*Foundations of Differentiable Manifolds and Lie Groups* (GTM 94).

| Edition | Reading copy | Template |
| --- | --- | --- |
| Color | [main_color.pdf](Notes/LectureNotes/output/main_color.pdf) | Original ElegantBook theme with layout refinements |
| Plain | [main.pdf](Notes/LectureNotes/output/main.pdf) | Restrained book layout |

Both editions share corrected numbering and references, 52 editable vector
figure replacements, a linked notation index, and clearly marked teaching
appendices. The source text originated from OCR; this is a study reprint,
not a fully collated critical edition.

See the [build instructions](Notes/LectureNotes/README.md) and
[revision notes](Notes/LectureNotes/REVISION.md) for the changes and verification scope.
